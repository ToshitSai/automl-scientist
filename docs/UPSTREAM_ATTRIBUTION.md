## Derived & Inspired Concepts

- **Agentic Tree Search**: Progressive experiment tree branching where each experiment node tracks hypotheses, code, metrics, and parent-child relationships.
- **Sandboxed Execution**: Isolated execution of LLM-generated Python code with captured `stdout`, `stderr`, runtime timeouts, and metrics logging.
- **Scientific Report Compilation**: Machine-generated Markdown research reports summarizing objectives, dataset inspection, baseline models, experiment runs, error analysis, and conclusions.
